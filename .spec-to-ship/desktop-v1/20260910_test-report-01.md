## 失败、修复与回归

1. Logo 合成到不透明图片后 alpha 变为 254：改成整数 source-over 合成，回归断言目标 alpha 严格等于 255，已通过。
2. 文字缺失提示同时出现在画布和表单，测试查询歧义：保留 UI 提示，测试明确验证两个提示及导出禁用，没有弱化业务断言。
3. jsdom 没有布局尺寸，虚拟列表测试不渲染项目：测试环境提供实际测量需要的 offsetWidth/Height，移除测试通过。
4. 初版 Mac bundle 的可执行签名不覆盖资源：配置 ad-hoc 包签名，codesign 校验通过。
5. DMG Finder 美化步骤在交互环境失败：CI 模式打包成功，保留失败记录；不使用旧 DMG 冒充当前版本。
6. 已导入文件后来丢失被整批前置校验拦截：已授权路径交给逐文件处理，允许部分失败与修复后重试，新增桌面回归测试通过。

## 性能

独立 release 核心处理 24MP PNG → 平铺中文水印 → JPG。两次观察处理耗时分别约 0.366s 与 1.635s（后一次并发构建期间），后一次最大 RSS 399,605,760 字节，峰值 footprint 380,813,960 字节。不是性能承诺或所有照片的平均值。另有 100 张 320×240 合成图批量测试；不把它称为 100 张大图压力测试。
