3. 构建应用与安装应用通过包签名完整性检查；仅依赖 Apple/系统动态库，未出现本机 Homebrew 动态库路径。

5. 新增通知、模板与布局修复的前后截图、元素坐标及浏览器交互见 `_reports/bug-fixes/20260910-workspace/fix-report.md`。此部分浏览器使用 API 替身；最终安装包已重新构建、安装并实际启动；原生 AX 显示已恢复证件水印设置，空状态正常。

## 曾失败的检查及修复

- 透明 Logo 合成使不透明 alpha 从255变254：改为精确整数 source-over，严格像素断言通过。
- 空 Logo 提示在表单和画布各出现一次导致测试查询歧义：明确验证两处提示及导出禁用，不降低业务要求。
- jsdom 无布局尺寸导致虚拟列表缺项：测试环境补充实际需要的元素尺寸，移除流程回归通过。
- 初始 Mac 签名只覆盖可执行文件：配置整个 bundle 的 ad-hoc 签名，完整性检查通过。
- 交互环境 DMG Finder 美化失败：CI 模式重新打包并验证，不复用失败批次产物。
- 导入后文件丢失使整批前置校验中断：已授权路径进入逐文件错误处理，部分失败和重试回归通过。
- 用户反馈模板无选中态、通知缺少目录入口及不自动关闭、两栏高度不齐：修复并新增3项行为测试，全部通过。

## 性能观察及未覆盖范围

24MP（6000×4000）PNG 加中文平铺水印转 JPG，在本机 release 核心两次观察约0.366秒与1.635秒（后者同时进行构建），后一次最大 RSS 399,605,760 字节。不是稳定基准或性能保证。100张测试使用320×240合成图，不声称完成100张大图压力测试。

未完成 Windows / Intel Mac 的人工安装与视觉操作、多个显示缩放比例、全量色彩配置和真实设备照片库、断电/磁盘满故障注入、长期运行泄漏测试。当前不支持 HEIC、RAW、PDF、视频和动画，WebP 输出无损；这些不属于本版验收范围。

平台信任限制：没有 Apple Developer ID/公证与 Windows Authenticode，因此发布为明确标注的预览版。系统可能提示未知发布者；ad-hoc 验签通过不等于通过 Gatekeeper。
