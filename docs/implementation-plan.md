# v0.1.0 实施基线

基于 product-and-stack.md 与已确认原型，交付本地图片水印桌面应用。仓库：https://github.com/chujianyun/wmark。

## 验收编号

- R01 导入 JPG/PNG/静态 WebP，批量与拖放；坏文件隔离；方向校正，尺寸限制。
- R02 文件列表、缩略图、选择/全选、移除、空状态、虚拟滚动。
- R03 中文文字与图片 Logo；颜色、透明度、旋转、比例、九宫格、平铺间距。
- R04 同一 Rust 渲染引擎预览/导出，原图比较、缩放、拖动定位、键盘微调。
- R05 内置模板与持久化多模板；设置恢复；缺失 Logo 可重新选择。
- R06 导出弹窗：范围、目录、格式、JPG 质量、背景、后缀；不覆盖源文件与已有文件。
- R07 串行批量任务、参数快照、进度、取消、部分失败、只重试失败、打开目录。
- R08 元数据隐私、色彩转换、EXIF 方向、动画拒绝、内存限制和错误恢复。
- R09 Mac/Windows 构建、CI 测试、版本标签触发 Release；签名凭据可选且如实标记。
- R10 完整测试、门禁报告、Mac 安装与实际 UI 冒烟。

## 实施决策

- 核心单独 Rust crate，桌面 IPC 薄封装；CPU 工作放阻塞工作池，图像处理串行限流。
- 使用 resvg/usvg/tiny-skia 的文本整形与合成，嵌入 OFL 的 Noto Sans CJK SC 字体，保证两端中文一致。首期提供同一字体的常规和加粗样式，不依赖系统字体。
- 使用普通 CSS 复用原型视觉令牌、React hooks 管理界面状态；Radix Dialog 处理焦点和弹窗可访问性。不为选型表而引入不必要的状态库。
- WebP 首期无损输出，因此只有 JPG 显示质量；避免呈现无效质量控件。
- 输出固定移除 EXIF/XMP（包括 GPS），界面明确告知，不提供保留私人元数据开关。ICC 转换后按 sRGB 输出。
- 动态 PNG/WebP 拒绝；单图最大 40MP，编码文件最大 200MiB，文字最大 100 字符；限制并反馈，而非崩溃。
- 发布流水线只在所有平台测试/打包成功后创建 Release；未配置签名证书时发布明确标注的未签名预发布版本，不声称通过平台信任验证。

## 顺序

核心与测试 → Tauri 接口与任务 → React 界面 → 全量检查/修复 → 构建安装/实际验收 → 测试报告与审查 → Git 与 CI/Release。

## 当前外部依赖

Git 推送使用已认证的 SSH；Release 工作流使用 GitHub 自动提供的最小权限令牌，无需开发机 gh 登录。Windows 验证通过 GitHub runner 获取，不将本地 Mac 结果当作 Windows 证据。
